# Sabor Express

### Simulação de aplicação de cadastro de Restaurantes

Implementando as funções de:

- main( ): Essa função inicia o programa chamando as funções que vão interagir com o usuário
- exibir_nome_do_programa( ): Função responsável por exibir o titulo do programa no terminal
- exibir_opcoes( ): Função responsável por exibir as opções disponíveis na tela
- escolher_opcao( ): Função que interpreta o input do usuário e chama a função correspondente
- exibir_subtitulo(subtitulo): Essa função limpa a tela e exibe o subtitulo de cada opção
- voltar_menu_principal( ): Essa função retorna ao menu principal
- cadastrar_novo_restaurante( ): Essa função cadastra novos restaurantes no programa
- listar_restaurantes( ): Essa função exibe as informações dos restaurantes cadastrados
- alterar_status_restaurante( ): Essa função altera o status do restaurante entre ativado e desativado
- finalizar_app( ): Essa opção encarra o programa
- opcao_invalida( ): Essa função retorna mensagem de erro quando o usuário escolhe uma opção invalida
